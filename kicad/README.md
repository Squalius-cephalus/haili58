## Kicad Footprints

This project uses footprints from various repositories

 - [OLED Display 128x32](https://github.com/crides/kleeb/tree/master/display.pretty)
 - [Diode THT/SMD](https://github.com/foostan/kbd) 
 - [Power Switch MSK12C02](https://github.com/joe-scotto/scottokeebs/tree/main/Extras/ScottoKicad)
 - [nice!nano V2](https://github.com/joe-scotto/scottokeebs/tree/main/Extras/ScottoKicad)
 - [GLP Hotswap Socket](https://github.com/siderakb/key-switches.pretty)

Few of the footprints has been edited, those can be found in the **haili_project.pretty** directory.
