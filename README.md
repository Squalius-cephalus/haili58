
# Haili58

Haili58 is a nrf52840 based 58-key column staggered split keyboard. PCB uses hotswap sockets. Design is inspired from REVIUNG41 and Corne keyboards.

PCB is designed for MX and Gateron low profile key switches. The keyboard is designed to be used with a USB dongle.

<img width="1280" alt="haili58 GLP and MX variant" src="https://github.com/user-attachments/assets/5d765860-2fae-430f-94be-020a7ffe848a" />

### Bill of materials
* 58 x MX Compatible Switches or GLP(KS-33) Switches
* 58 x Kailh Hotswap Sockets or GLP Hotswap Sockets
* 58 x 1N4148 Diodes or 1N4148W T4 SOD-123
* 58 x 1u keycaps
* 3 x nrf52840 Pro Micro
* 2 x PJ320D audio sockets
* 2 x EC11 Encoders
* 16 x M2 Heat set inserts, length 2mm(OD3.2mm)
* 16 x M2 bolts, length 5mm
* 2 x MSK12C02 Slide Switch
* 2 x 6x6x4.3MM 4PIN G89 Tactile Tact Push Button
* 2 x 14500 Battery with protection chip
* 2 x 14500 Battery holder(AA holder works or you can use [printed holder](https://github.com/Squalius-cephalus/haili58/tree/main/case/battery_holder))
* 2 x [PCB](https://github.com/Squalius-cephalus/haili58/tree/main/gerber)
* [Case Files](https://github.com/Squalius-cephalus/haili58/tree/main/case)
* [Case for the dongle](https://www.printables.com/model/1285346-pro-micro-nicenano-nrf52840-dongle-case/files)
